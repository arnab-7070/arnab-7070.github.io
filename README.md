# Arnab Mandal | Portfolio

My personal portfolio website, built by hand with HTML, CSS and JavaScript and hosted on GitHub Pages.

**Live site:** https://arnab-7070.github.io/

## About

I'm a B.Tech Computer Science Engineering student at the Institute of Engineering and Management (IEM), Kolkata, graduating in 2027. This site collects my skills, projects and certificates in one place.

## Features

- Responsive layout that works on phones, tablets and desktops
- Animated headline, floating photo card and a typing code snippet
- Scroll animations and a scrolling skills strip
- Respects the "reduce motion" setting for visitors who prefer less movement
- No frameworks or build step, just three files

## Built with

- HTML5
- CSS3 (custom properties, grid, flexbox, keyframe animations)
- JavaScript (no libraries)
- Google Fonts: Inter Tight and JetBrains Mono

## Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/arnab-7070/arnab-7070.github.io.git
   cd arnab-7070.github.io
   ```
2. Open `index.html` in a browser. In VS Code, the Live Server extension reloads the page as you edit.

## Project structure

```
├── index.html    # page content
├── style.css     # styles and animations
├── script.js     # interactions and animations
└── photo/        # profile picture
```

## Deployment

The site is deployed with GitHub Pages from the `main` branch. Every push to `main` updates the live site in a minute or two.
